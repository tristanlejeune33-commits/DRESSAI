# DressAi - Votre Styliste Personnel IA

Application web d'analyse de style et de recommandation de tenues basée sur l'IA.

## Fonctionnalités
- Analyse morphologique
- Colorimétrie
- Recommandations contextuelles
- Génération de tenues via IA

## Déploiement
Ce projet est prêt à être déployé sur Vercel.
1. Poussez le code sur GitHub.
2. Importez le projet dans Vercel.
3. Le fichier `index.html` sera automatiquement servi.
